# Screen Demo Title Authoring

## Overview

Use this project-local skill to write the title after source selection and repo research.

## Rules

- Do not write the title before the covered repos and their actual angle are known.
- Reuse the existing creator writing lane instead of inventing a second title system.
- Keep the title tied to the episode promise, not just a repo list.

## Supporting Skills

- Use `$content-creation` for the final writing pass.

## Current Boundary

- This skill documents the proper stage order.
- The title generation step is not yet auto-wired into `npm run screen-demo`.
