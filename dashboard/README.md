# Harness Dashboard Shell

Dashboard shell for the localhost harness.

Files:
- `index.html`
- `styles.css`
- `app.js`
- `data.js`

The page now talks to the localhost harness API for:
- run creation
- discovery execution
- run listing
- artifact listing

Manual polish stays outside the app:
- this dashboard should produce the trimmed MP4 handoff
- Cursorful or Recordly edits happen manually afterward
- the post-polish step will ingest the returned MP4 later
