# Screen Demo Description Authoring

## Overview

Use this project-local skill for the description stage after source selection and repo research.

## Rules

- Keep the description downstream of the actual research.
- Include the real repos covered and the actual promise of the episode.
- Reuse the creator copy lane instead of inventing a one-off description writer.

## Supporting Skills

- Use `$content-creation` for the final writing pass.

## Current Boundary

- This skill is documented and ready for orchestration.
- The description stage is not yet auto-wired into `npm run screen-demo`.
